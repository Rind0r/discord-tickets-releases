# Сборка выпущенной версии

Для пользователей готовый EXE находится в GitHub Releases. Этот документ нужен для воспроизведения сборки из исходников.

Нужны Windows 10/11, Git, Node.js 24, pnpm 12.15.0 и штатный .NET Framework. Запустите из корня:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build-Installer.ps1
```

Скрипт получает Vencord с коммита, указанного в `release.json`, копирует исходники `plugin/discordTickets` в `src/userplugins`, устанавливает зависимости из lockfile, проверяет TypeScript и ранний импорт до готовности React, собирает Vencord с отключённым штатным обновлением. Затем получает официальный Vencord Installer указанной версии и проверяет его SHA256, создаёт исходный архив и компилирует установщик штатным `csc.exe`. Результат находится в `dist`. Discord при сборке не изменяется.

Соответствующие исходники Vencord и официального Installer также находятся внутри EXE в `source`. Он проверяет SHA256 встроенного пакета командой `Discord-Tickets-Setup.exe --verify`. Команда `--self-test` проверяет валидацию обновлений без сети и установки.

`installer/Engine.ps1` содержит установку, резервное копирование и откат. `installer/Launcher.cs` — распаковку и получение обновлений только из настроенного GitHub Releases. `release.json` задаёт версии и адрес публикации. Для выпуска следующей версии увеличьте номер, проверьте установку/обновление в отдельном Windows-профиле или VM и опубликуйте новые EXE и `latest.json` вместе. Контрольные суммы защищают от повреждения; цифровую подпись автора они не заменяют.
