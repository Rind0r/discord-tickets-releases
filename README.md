# Discord Tickets

**by Luf · версия 1.0**

Плагин для Discord с личными шаблонами ответов в обращениях поддержки. Выбранный шаблон вставляется в поле сообщения. Отправку вы выполняете сами.

## Установка

Подходит для Windows 10/11 и обычного Discord, Discord PTB или Canary. Установлен у вас Vencord или нет — порядок одинаковый.

1. Скачайте **[Discord-Tickets-Setup.exe](https://github.com/Rind0r/discord-tickets-releases/releases/latest/download/Discord-Tickets-Setup.exe)**.
2. Сохраните несохранённые изменения в Discord и завершите звонок.
3. Запустите файл и подтвердите установку. Если найдено несколько версий Discord, выберите нужную.

Установщик подключит Vencord с плагином и запустит Discord заново. При первой установке плагин включается автоматически. Отдельно устанавливать Vencord, Git или Node.js не нужно.

## Обновление

В меню **Пуск → Discord Tickets** выберите **«Обновить Discord Tickets»**. Либо скачайте установщик по той же ссылке и запустите его повторно.

Ваши шаблоны, настройки и выбранное приветствие сохраняются. Там же в меню «Пуск» есть **«Откатить Discord Tickets»** для возврата предыдущего подключения. Если после обновления Discord пропал Vencord, повторно запустите установщик.

## Использование

- Кнопка плагина рядом с полем сообщения открывает настройки области действия и приветствия.
- Нажмите на пустое поле, чтобы увидеть приветствие, или введите от двух символов для поиска шаблона.
- Первый выбранный шаблон заменяет текст черновика. Чтобы продолжить ответ другим шаблоном, нажмите **«Добавить ещё шаблон»**. Всё уже написанное сохранится.
- Через **«Все шаблоны»** можно добавлять и редактировать свои ответы.
- **«Упомянуть»** добавляет переменную `{автор}`. При вставке она заменяется упоминанием создателя обращения, если его удалось определить.
- Для переноса своих шаблонов используйте экспорт и импорт JSON.

## Важно

Установщик пока без цифровой подписи, поэтому Windows может показать предупреждение. Он не отключает защиту системы. Другие пользовательские плагины из сторонних сборок Vencord автоматически не переносятся. Браузерный Discord, Microsoft Store и другие операционные системы этим установщиком не поддерживаются.

Шаблоны хранятся локально. Для проверки обновлений установщик обращается к GitHub. Исходники выпущенной версии доступны в этом репозитории и в архиве выпуска. Лицензия — GPL-3.0-or-later.
